# Semester Result Analysis Dashboard

A Python-based data analytics dashboard for analyzing and visualizing student semester results. The application processes student marks, calculates percentages, grades, pass rates, and performance statistics, and presents the insights through an intuitive and professional dashboard.

## Features

* Student result analysis and performance tracking
* Automatic percentage, grade, and pass/fail calculation
* Class average and pass-rate analysis
* Subject-wise performance analysis
* Grade distribution visualization
* Semester and section comparison
* Top-performing student identification
* Attendance vs. academic performance analysis
* Student search and filtering
* CSV data import and export
* Interactive tables and visual charts
* Clean, modern, and professional Tkinter interface
* Optional MySQL database support

## Technologies Used

* **Python** – Core application development
* **NumPy** – Numerical and statistical operations
* **Pandas** – Data processing, cleaning, filtering, and aggregation
* **Matplotlib** – Data visualization
* **Tkinter** – Graphical user interface
* **MySQL** – Optional database integration
* **Pytest** – Automated testing

## Dashboard Sections

### Overview

Provides a quick summary of overall academic performance using KPI cards, grade distribution, and key insights.

### Performance Analysis

Displays subject-wise averages, semester trends, strongest and weakest subjects, and attendance-performance relationships.

### Student Analysis

Provides individual student performance details including percentage, attendance, grade, and result status.

## Project Objective

The main objective of this project is to automate semester result analysis and transform raw student result data into meaningful, easy-to-understand visual insights that support academic monitoring and decision-making.

## Benefits

* Reduces manual result calculations
* Minimizes calculation errors
* Saves time during academic analysis
* Makes large result datasets easier to understand
* Helps identify academically strong and weak areas
* Supports data-driven academic decisions
